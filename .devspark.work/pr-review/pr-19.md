## Security

One finding: **H-01**, a timing side channel in `LoginAsync` that can distinguish an unregistered email from a wrong password by response latency, contradicting the endpoint's own documented account-enumeration resistance. No hardcoded secrets, no SQL injection (EF Core LINQ, fully parameterized), no XSS (account data is never rendered as raw HTML), and no new third-party dependencies — `PasswordHasher<Account>` and the cookie-authentication middleware both ship in the ASP.NET Core shared framework `Rite.Api.csproj` already references (`Microsoft.NET.Sdk.Web`), so no `PackageReference` was added for either.

### Observations
